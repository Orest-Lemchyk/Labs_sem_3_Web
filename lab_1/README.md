Вимоги:

Опис: Покращте цільову сторінку відповідно до заданого дизайну (такого ж, як і в попередньому), додавши повну адаптивність та трохи анімації.
Вимоги:

    ● Вебсайт має бути частково адаптивним:
    Обов'язково: для 320px (iPhone 5s) 2560px (екрани 4K).

Підказка: для екранів дуже великої ширини ви можете просто вмістити вміст вебсайту в попередньо встановлений контейнер для звичайної ширини екрана та відцентрувати його по горизонталі.

    ● Заголовок повинен згортатися до гамбургера на маленьких екранах.

    ● Вебсайт повинен містити анімацію (принаймні 3). Можна зробити будь-яким можливим способом, бажано з властивостями css (анімація/перехід).

    ● Ваш проект має бути логічно структурованим (весь ваваш CSS не може бути лише в одному-двох файлах).

    ● Усі попередні вимоги до роботи мають бути збережені.
