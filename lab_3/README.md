CRUD Javascript App: View Page

Опис:
    У цій роботі вам потрібно створити просту 
    презентацію веб-сайту - Перегляд сторінки

Для ваших блоків ви повинні використовувати 
дані з вашого класу проекту java/python.

Якщо у вас немає даних за попередній рік, 
ви повинні вибрати будь-яке безкоштовне завдання

    Створити клас “Взуття” котрий містить поля:
    ● назва виробника
    ● ціна
    ● розмір
    ● колір


Потім, використовуючи JavaScript, вам потрібно реалізувати 
наступні операції над вашими даними (вам вирішувати, яке 
поле слід використовувати для кожної з операцій):
    ● Опція сортування ваших товарів
    ● Опція пошуку
    ● Підрахувати загальну суму деяких полів
    (наприклад, загальна ціна всіх автомобілей)

Вимоги:
    ● Адаптивність абсолютно не потрібна.
    ● Стилізація взагалі не важлива.
